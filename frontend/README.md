# Frontend - blog helper

Za instalaciju i pokretanje frontend aplikacije, morate imati instaliran [Node.js](https://nodejs.org/en).

## Postavljanje i instalacija paketa
1. `touch .env`
2. `cat .env.template > .env`
3. `npm ci`
4. `npm run dev`

Otvorite browser na adresi [http://localhost:5173](http://localhost:5173)
